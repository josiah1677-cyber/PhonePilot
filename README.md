# PhonePilot

![PhonePilot app icon](phonepilot-icon.png)

PhonePilot is an Android app that lets different AIs control your phone. It reads what's on your screen and carries out taps, swipes, scrolling, app launches and text entry using an AI API key you provide. It works with OpenAI-compatible services (OpenAI, OpenRouter, Groq, DeepSeek, Together, Ollama, etc.) as well as Anthropic and Google Gemini.

It also has a built-in chat screen, so you can just message the AI like Gemini — ask normal questions or tell it to do something on your phone, and it will handle it and report back.
